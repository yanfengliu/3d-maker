## `src/repo-conventions.test.ts`

It fails when any file under `src/` or `scripts/` exceeds **500 lines** (inclusive bound, reported with every offender's path and count; `src/iphone/materials.ts` is committed at exactly 500 and `scripts/sweep-iphone.mjs` sat at exactly 500 for three rounds, so the bound is stated as inclusive rather than reddening a file nobody owns), and when any file under `src/` reads a runtime control channel — the Vite or Node env objects (zero matches allowed) or the page URL, which is allowed only at the three **declared** `new URL(…)` reads of the query contract, checked in both directions so adding, moving or silently deleting one fails. Its bounds: an alias (`location`, `globalThis.location`) is invisible, `vite.config.ts` and files outside `src/`/`scripts/` are out of scope, and it reads physical lines, not statements.

## `npm run check:finishes`

It drives its own headless Chrome over CDP and has four always-on sections: (1) the `back` view's rail-over-panel relative-luminance ratio for all three finishes, failing outside ±0.05 of its reference (cosmic-orange 0.73, deep-blue 0.47, silver 0.87); (2) the `bottom` view's port through three named rects (pocket ≤ 25 luma, tongue 25–70, rail 70–200, with `tongue − pocket ≥ 15` and `rail − tongue ≥ 25`); (3) the cover glass on the `front`, `right` and `left` presets, one named rect each — median inside 45..85 and spread ≥ 70 on `front` and `right`, median only on `left`, which is a flat mirror whose reflected ray sweeps 0.1° and physically cannot carry structure (round 11's measurement; the gate's header says so, so nobody "fixes" it); and (4) `--graze`, which shoots a grazing close-up of the plateau's roll through the page's real pointer input and fails on any run of pixels at luma ≤ 3. The entry file holds the contract, the args and the exit codes; each section's bounds live with the module that owns them under `scripts/lib/`. **Local gate**: it needs a running dev server (`SHOT_BASE`, default `http://localhost:5199`) and Chrome (`SHOT_CHROME`), so it is not part of `npm run verify`, and CI runs no pixel check at all beyond `npm run build` — the input pins in `materials.test.ts`/`optics.test.ts`/`tone.test.ts` are the half CI can run, and neither half replaces the other. Its bound is those frames and rects: the ends, the plateau's face, the bezel and island, and every other surface go unmeasured; it cannot see an aperture's *shape* (that is `aperture.test.ts`) or where the tongue sits (`port.test.ts`); and the `back` ratio's two bands are flat faces, so it cannot see a surface whose normal turns. `--targets a=0.73,b=0.47,c=0.87` overrides the references. Exit 2 means it could not measure at all (no dev server, no Chrome, no `window.__shotReady`, a canvas not at 1400x1000, a rect reading black or landing off-canvas), which is not the same claim as a failed look.
