# Studio gates

Use Node 24 and the committed lockfile. Run `npm run verify` for unit tests (including the append-only model variation lockfile and Git-history monotonicity guard in `src/models/variations-guard.test.ts`, plus the deterministic geometry craft invariants in `src/models/craft-invariants.test.ts` enforcing zero unintended floating parts, zero exposed coplanar Z-fighting, watertight 6-direction coverage, grounding, detachable-part integrity, and PBR material hygiene across every variation), typecheck, lint, both Vite outputs, and the post-build bundle-size & SDK export gate (`npm run check:bundle`). The second output is a single ES module whose three.js imports resolve to the consuming game’s own dependency. After adding new model variations in `src/models/variations.ts`, run `npm run variations:lock` to record them in `src/models/variations.lock.json` (never delete locked variations; see `docs/policies/local-rules.md`). GitHub Actions runs a split `build` + `deploy` Pages workflow: `build` runs `npm run audit:runtime`, `npm run verify`, and `npm run check:studio:ci` (bounded headless browser smoke suite) before uploading the Pages artifact, and `deploy` publishes it independently so retries stay fast.

After a build, `npm run check:studio` serves the real production output at a GitHub Pages-style subpath and launches a local GPU-accelerated headless Chrome, running the full interactive suite (with `verifyClipFraming`, `verifyCapabilities`, and `verifyRemixes` in parallel isolated browser contexts). Set `SHOT_CHROME` if Chrome is outside the detected locations. The check exercises mouse orbit, fixed camera views, perspective/orthographic projection and cross-port persistence, visible pixels, six poster images, customization, local persistence across reload, character playback, binary export and reimport, capabilities, remixes, and the external SDK. `npm run check:studio:ci` runs the fast core smoke subset for CPU-bound Linux CI runners. `npm run inspect:model -- <id>` renders all six cardinal views (`Front`, `Back`, `Left`, `Right`, `Top`, `Bottom`) plus `3/4` and geometry metrics into ignored `output/inspect/` for visual defect inspection. Inspect the desktop, category, orbit, and 6-angle screenshots in ignored `output/`. For a live catalog change, also open a real result and check the final page against the publisher.

Run `npm run capture:posters` against the dev server at `http://127.0.0.1:5199` after changing model appearance. Set `SHOT_BASE` for another port. The six compressed library previews are product assets.

After a dependency change, run `npm run audit:full` and `npm run audit:runtime`. Verify the local dataset independently with `node scripts/dataset.mjs --verify`.
